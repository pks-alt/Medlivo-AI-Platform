# Recruiter UX

## Home: Today
Action-first, not ATS-first.

Primary blocks:
- Needs Your Attention
- AI Working For You
- Priority Jobs
- Recent Candidate Responses

## Navigation
Today | Jobs | Candidates | Customers | Conversations | Submissions | Analytics

## Recruiter context
Each recruiter has:
- own profile
- assigned customers
- assigned jobs
- candidate ownership
- specialties
- permissions
- team context

Managers see broader team/division scope.

## Submission-ready packet
One-screen review with:
- score
- evidence
- qualification
- location/license readiness
- availability
- compensation fit
- conversation summary
- gaps
- Approve / Hold / Reject / Submit
