# Phase 1 Product Spec

## Outcome
Increase submission-ready candidates per recruiter while reducing recruiter effort.

## First production release
- recruiter command center
- job and candidate intelligence
- selective matching/ranking
- recruiter-approved SMS + email outreach
- AI qualification
- Near Ready / Submission Ready workflows
- basic manager dashboard
- JobDiva read integration first, write-back as supported

## Pilot
Mixed recruiter group across Nursing & Allied, Rehabilitation, and Locum Tenens.

Measure:
- time to first strong match
- submission-ready candidates per recruiter
- recruiter time saved
- submissions
- interviews
- placements
- before/after plus control group

## Deliberately deferred
- public marketplace
- full clinician marketplace UX
- autonomous submission
- Neo4j production layer
- AI voice
