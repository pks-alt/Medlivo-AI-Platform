# Phase 1 Implementation Roadmap

## 0. Foundation
- repository and documentation
- recruiter UX prototype
- security/RBAC model
- event contracts
- cloud project plan

## 1. JobDiva Connector Proof
- authenticate securely
- pull controlled set of jobs
- pull controlled set of candidates/resumes
- preserve source IDs
- confirm incremental/webhook strategy

## 2. Candidate + Job Intelligence
- normalization schemas
- healthcare taxonomy
- evidence/provenance
- identity resolution
- freshness model

## 3. Search + Matching
- hard gates
- hybrid retrieval
- scoring rules
- explanations
- recruiter shortlist

## 4. Recruiter Command Center
- Today queue
- Jobs
- Candidate profile
- Customer ownership
- match review
- natural-language + structured search

## 5. Outreach + Qualification
- SMS/email abstraction
- approval workflow
- two-way replies
- AI qualification
- Near Ready / Submission Ready

## 6. Pilot
- mixed recruiters across all 3 divisions
- control group
- measure submission-ready volume, time saved, submissions, interviews, placements

## 7. Scale
- expand ingestion toward full ~1M resumes
- production hardening
- broader recruiter rollout

Marketplace work is intentionally deferred to Phase 2.
